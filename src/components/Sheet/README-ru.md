# Sheet

<!--/GITHUB_BLOCK-->

```tsx
import {Sheet} from '@gravity-ui/uikit';
```

Компонент `Sheet` (шторка) предназначен для использования в мобильных интерфейсах в качестве информационного или интерактивного элемента. Благодаря поддержке внутренней прокрутки и динамического изменения размеров в него можно помещать контент любого объема.

На мобильных устройствах `Sheet` можно перемещать, потянув за его основную часть или область свайпа. Для закрытия нужно провести вниз, коснуться области вне `Sheet` или нажать `Escape`.

## Использование

```tsx
import React from 'react';
import {Button, Sheet} from '@gravity-ui/uikit';

const SheetExample = () => {
  const [open, setOpen] = React.useState(false);

  return (
    <React.Fragment>
      <Button onClick={() => setOpen(true)}>Open Sheet</Button>
      <Sheet open={open} onOpenChange={setOpen} title="Content Sheet">
        Content
      </Sheet>
    </React.Fragment>
  );
};
```

## Фокус и управление с клавиатуры

При открытии шторки фокус получает сама шторка. Фокус удерживается внутри шторки, а фон
скрывается от вспомогательных технологий. Фокус на шторке, а не на первом элементе, не даёт
текстовому полю открыть экранную клавиатуру. После закрытия фокус возвращается на открывший её
элемент.

Свойство `initialFocus` позволяет перевести фокус на элемент внутри шторки, а `returnFocus` —
изменить или отключить возврат фокуса. Для шторок, которые не должны удерживать фокус и скрывать
страницу, задайте `disableModal`: такая шторка оставляет фокус на месте, если не передан
`initialFocus`, и не добавляет кнопки закрытия. Она по-прежнему участвует в стеке слоёв, поэтому
Escape закрывает её, если не задан `disableEscapeKeyDown`; свайпы и поведение подложки сохраняются.

Вспомогательным технологиям доступны визуально скрытые кнопки закрытия, как в `Modal`. Нажатие
вызывает `onOpenChange(false, event)` без причины. Как и при других способах закрытия, управляемая
шторка остаётся открытой, пока родитель не изменит `open`. Свойство `disableVisuallyHiddenDismiss`
убирает эти кнопки, например, если у шторки есть своя кнопка закрытия.

Шторки могут быть вложенными или открываться одна за другой. Escape закрывает только верхнюю
шторку, а фокус возвращается на открывший её элемент. Шторка внутри `Modal` или другого плавающего
элемента обрабатывает Escape первой, поэтому следующий Escape закрывает родителя.
