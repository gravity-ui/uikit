# Sheet

<!--/GITHUB_BLOCK-->

```tsx
import {Sheet} from '@gravity-ui/uikit';
```

Компонент `Sheet` (шторка) предназначен для использования в мобильных интерфейсах в качестве информационного или интерактивного элемента. Благодаря поддержке внутренней прокрутки и динамического изменения размеров в него можно помещать контент любого объема.

На мобильных устройствах `Sheet` можно перемещать, потянув за его основную часть или область свайпа. Для закрытия нужно провести вниз, коснуться области вне `Sheet` или нажать `Escape`.

## Использование

```tsx
import React from 'react';
import {Button, Sheet} from '@gravity-ui/uikit';

const SheetExample = () => {
  const [open, setOpen] = React.useState(false);

  return (
    <React.Fragment>
      <Button onClick={() => setOpen(true)}>Open Sheet</Button>
      <Sheet open={open} onOpenChange={setOpen} title="Content Sheet">
        Content
      </Sheet>
    </React.Fragment>
  );
};
```

## Закреплённый заголовок

Включите `stickyTitle`, чтобы `title` оставался видимым при прокрутке основного контента. Существующий `title` принимает строку или React-узел. Объедините заголовок, инпут и другой контент в `title`, чтобы закрепить их единым блоком без дополнительных пропсов или вычисления отступов.

```tsx
<Sheet
  open={open}
  onOpenChange={setOpen}
  stickyTitle
  title={
    <Flex direction="column" gap="spacing-3" role="group" aria-label="Projects">
      <Text as="h2" variant="subheader-3">
        Projects
      </Text>
      <TextInput placeholder="Search projects" controlProps={{'aria-label': 'Search projects'}} />
    </Flex>
  }
>
  {/* Прокручиваемый контент */}
</Sheet>
```

Строковый заголовок сохраняет стандартную типографику и обрезку многоточием. Составной заголовок использует собственную раскладку и может содержать интерактивные элементы. Доступное имя диалога задаётся через `aria-labelledby`; `aria-label` на корневой группе позволяет сделать его кратким.

Для закрепления только штатного заголовка используйте `title="Projects" stickyTitle`. Без `stickyTitle` заголовок прокручивается вместе с основным контентом. Контент из `children` остаётся в основной области прокрутки.

Если высота заголовка равна высоте видимой области контента или превышает её, `Sheet` автоматически отключает закрепление: заголовок и основной контент прокручиваются вместе, поэтому заголовок не скрывает содержимое шторки. Когда заголовок снова помещается, закрепление восстанавливается. Проверка повторяется при изменении размера заголовка или видимой области, в том числе при изменении окна и появлении клавиатуры. Заголовок может быть выше основного контента и оставаться закреплённым, если он помещается в видимую область.

Заголовок и основной контент используют общий скролл-контейнер. При `allowHideOnContentScroll` новый свайп вниз от верхней границы закрывает шторку. Если жест прокрутки довёл контент до верха, для закрытия нужно отпустить палец и начать следующий свайп.

| contentClassName            | HTML-атрибут `class` для контента шторки.                                                                                                                                                                                                                                                                                                                                          |     `string`      |      `undefined`      |
